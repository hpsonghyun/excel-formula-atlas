Know what the map is working on.

While the viewer prepares a large workbook, the loading panel shows the current stage, completed items, percentage, and elapsed time.

The percentage follows actual preparation work. Once the map is ready, the panel closes automatically.

Large drawing tasks run in chunks so progress can update. Errors show an explanation and a retry action.

One module.
Your workbook's map.

The TXT file contains the analyzer, viewer, and local navigation helper. You do not need companion source files, a Python installation, or an Excel add-in on the PC where you use it.

  1. Paste the code

    Download the VBA code (.txt) and copy all its contents. In Excel, press Alt + F11 and choose Insert → Module to create a new standard module with no existing user code. In that new module's code window, press Ctrl + A and paste, replacing any automatic Option Explicit. Keep your existing macro modules intact. Save the code-hosting workbook as .xlsm.

  2. Run the macro

    Press Alt + F8 in Excel and run the macro below. Choose 1 for the current workbook or 2 to pick an Excel file, then choose an output folder.

    ExcelMap_Start

  3. Explore the HTML

    Open the exported page, find a result, and trace its sources. When the local Windows connection is available, you can jump back to the matching cell in the open Excel workbook.

Keep the generated map with the same care as the workbook. The HTML includes captured sheet names, values, formulas, and file metadata. Review it before sharing. Run the macro again after changing the source workbook.

A few practical details.

The map is a way into a workbook. These boundaries help you use it with confidence.

Which versions of Excel can use it?

The macro targets desktop Microsoft Excel on Windows. It needs permission to run VBA. Excel for the web and Excel for Mac are not supported by this release. A modern browser can open the standalone HTML map.

Does my workbook leave my computer?

The analysis runs locally in Excel. The exported viewer uses an embedded snapshot and does not need a workbook upload, cloud account, external font, or analytics service. The HTML itself contains captured workbook data, so share it as carefully as you would share the workbook.

Will analysis change my formulas?

The analyzer reads the source and writes a separate HTML file; it does not rewrite source formulas. A selected file opens read-only with external-link updates off and VBA macros disabled. Excel may still prompt about legacy Excel 4.0 macros. Installing the module changes the workbook in which you choose to store the macro.

Can the HTML select a cell in Excel?

The export attempts to start a bundled local Windows helper that connects the page to the open workbook. Organizational policies can prevent that connection. If it cannot start, you can still open the saved HTML and explore the static map. Run ExcelMap_Stop to stop the navigation connection when you finish.

Does it resolve every kind of formula?

No. Dynamic references such as INDIRECT and some OFFSET formulas cannot always be resolved from formula text alone. Advanced reference forms and capture limits can leave gaps. Treat reported limitations as part of the map, and compare important findings with Excel.

What happens with a large workbook?

Analysis is bounded to 50,000 formula cells. Each sheet snapshot is bounded to 2,000 rows, 256 columns, and 20,000 captured cell positions. The full-workbook view draws up to 700 connections at once; select a cell or area to explore a specific flow. Large maps show loading progress but may still require time and browser memory.

Is the map a live view of my workbook?

It is a snapshot of values, formulas, and worksheet positions captured during analysis. Editing Excel does not update an already exported page. Run the macro again to create a fresh map.
